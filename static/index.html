Machine Learning Recommendation Architecture

01

Data Engineering & Feature Extraction

We process the TMDB 5,000 dataset, combining critical attributes into a unified textual metadata tag:

Tags = Plot Overview + Top 3 Genres + Keywords + Top 3 Cast Members + Director
02

NLP Vector Space Representation

Words are stemmed (PorterStemmer) and converted into a 5,000-dimensional vector space using CountVectorizer / TF-IDF, filtering out common stop words.

03

Cosine Similarity Matrix

Instead of Euclidean distance, cosine similarity measures the angle between movie vectors:

$$\text{Similarity}(A, B) = \cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|}$$

A score of 1.0 indicates identical content tags, while 0.0 indicates completely unrelated films.

04

Real-time Top-N Inference

When you query a movie, the FastAPI server accesses precomputed row similarity vectors and returns the top \(N\) closest neighbors in under 10 milliseconds!

Settings & Poster Customization
